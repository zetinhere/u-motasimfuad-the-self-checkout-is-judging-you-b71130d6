One funny line in the voice of a smug, judgmental self-checkout machine — the sort of remark the till would make to a shopper buying twelve yoghurts and nothing else. Thirty candidate lines were drafted; a proxy-judge tournament (pairwise, both orders, Swiss rounds plus a finals round-robin of the top six) was attempted against the bounty judge's published brief, but the model gateway was unavailable at tournament time, so the winner was picked by structured scoring against that same brief. The program writes the winning line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
